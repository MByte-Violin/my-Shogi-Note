# 将棋ノートアプリ (Shogi Note App)

- 将棋が上達したい人のための、対局分析・ノート記録・データ蓄積ツールです。
- 単に棋譜を保存するだけでなく、自分の「負けパターン」や「勝ちパターン」をタグで管理し、後で振り返りやすいノートを作成することで、効率的な学習をサポートします。
- **※利用規定を確認してから利用してください。利用している時点で同意したものとみなします。**

## 🚀 はじめて使う方へ（初期設定ガイド）

本ツールは、あなたのGitHubアカウントに自分専用の対局データを安全に保管します。  
GitHubが初めての方でも、以下の2つの準備をするだけで簡単に使い始められます。

### ① データの保存場所を作る（空のリポジトリ作成）
- GitHubで「新しいリポジトリ（New repository）」を **Private（非公開）** で作成します。
- テンプレートの選択やインポートは一切不要です。**「空のまま」作るだけ**で、アプリが自動で必要なフォルダやファイルを生成・管理します。

### ② 安全な連携キー（トークン）を発行する
アプリとリポジトリをつなぐための合鍵（トークン）をGitHubで発行します。セキュリティを守るため、GitHub推奨の「Fine-grained personal access token」を使用します。
- **このキーはクレジットカードの暗証番号と同じレベルで厳重管理してください。**
- **Repository access**: 「Only select repositories」を選び、①で作成した専用リポジトリのみを選択します。
- **「Read and write」の設定手順**:
  1. **`+ Add permissions` ボタンをクリック**  
     Permissions の枠内、右上にある **`+ Add permissions`**（青い枠線内のボタン）をクリックしてください。
  2. **一覧から `Contents` を探す**  
     権限の一覧（リスト）が表示されますので、その中から **`Contents`**（コンテンツ／ファイル）を探してください。
  3. **アクセス権を「Read and write」に変更する**  
     `Contents` の右側にある選択メニュー（初期状態は「No access」または「Read-only」）をクリックし、**`Read and write`** を選択してください。  
     ※将棋ノートアプリが対局データ（JSON）やノート・棋譜ファイルを読み書き・保存するために、この `Contents: Read and write` が必要となります。  
     ※（`Metadata` の Read-only 権限は自動的に付与されますが、そのままで大丈夫です。）
  4. **一番下の「Generate token」ボタンを押す**  
     画面の一番下までスクロールし、緑色の **`Generate token`** ボタンを押してください。

準備ができたら、アプリ内の設定画面で「ユーザー名」「リポジトリ名」「トークン」を入力するだけで利用開始できます！
